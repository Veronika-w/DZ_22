## Приложение Skystore - это отличный вариант хранения ваших плагинов и примеров кода, который вы бы хотели продать

## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/Veronika-w/DZ_22.git
```
2. Установите зависимости:
```
poetry install
```
3. Для запуска запустите в терминале команду:
```
python manage.py runserver
```

Реализованы страницы:
```
http://127.0.0.1:8000/home/
http://127.0.0.1:8000/contacts/
```
